# 播客笔记助手 UI 改造设计

日期：2026-05-25

## 目标

- 保留现有业务功能、处理流程和 IPC 逻辑，不新增业务能力。
- 将当前偏“工具页”的界面升级为轻后台工作台风格。
- 默认深色主题，支持用户手动切换浅色主题。
- 视觉风格参考提供的样图，但适配当前播客处理链路，不强行照搬多页面后台结构。

## 设计原则

- 单页工作流优先：不拆散当前输入链接、查看进度、停止/继续、查看最近任务的连续操作路径。
- 视觉升级优先：主要调整布局层级、卡片样式、状态展示和主题系统。
- 稳定大于炫技：保留科技感，但避免过重霓虹效果影响可读性和长期使用体验。
- 最小业务侵入：只改渲染层布局、样式和主题状态，不改处理语义。

## 目标布局

整体采用轻后台工作台结构：

- 左侧：装饰性侧栏
- 顶部：工具栏
- 中间：主工作区
- 右侧：状态和最近任务面板

布局说明：

- 左侧侧栏主要承担品牌、氛围和少量入口，不做复杂页面跳转。
- 顶部工具栏承担搜索外观位、主题切换、状态展示和窗口控制。
- 中间主工作区继续保留原有主流程，是用户最常停留的区域。
- 右侧面板集中展示最近任务和当前任务摘要，强化“工作台”感。

## 组件映射

### Header

现有 `Header` 升级为顶部工具栏，包含：

- 应用 Logo 和名称
- 搜索外观位
- 主题切换按钮
- 飞书状态胶囊
- 窗口控制按钮

调整目标：

- 从简单标题栏升级为更完整的产品顶栏。
- 保持 `WebkitAppRegion` 的可拖拽逻辑，同时避免交互控件失去可点击性。

### StatusBar

现有 `StatusBar` 不再作为独立信息条存在，功能合并到顶部右侧状态区：

- 飞书连接状态
- 监听状态
- 简洁的在线指示

调整目标：

- 减少重复占位
- 提升状态展示精致度
- 保留已有状态逻辑与文案语义

### UrlInput

现有 `UrlInput` 保留功能，但提升为主操作卡片：

- 更明显的输入主区域
- 更强的主按钮层级
- 补充简短提示信息
- 与上方欢迎区和快捷卡风格统一

调整目标：

- 让“粘贴链接开始处理”成为主视觉焦点
- 保留现在熟悉的输入方式

### StepPanel

现有 `StepPanel` 继续作为中部核心组件，但改为更完整的流程卡片：

- 顶部显示阶段标题和步骤标识
- 中部保留 5 步流程可视化
- 底部强化当前步骤说明、细节和进度展示

保留约束：

- 继续遵守“无真实进度就不乱动进度条”的现有规则
- 保留停止、错误、完成等已有状态表达

### ControlBar

现有 `ControlBar` 并入主流程卡片底部或下方统一操作区：

- 停止处理
- 继续处理
- 设置
- 清理缓存

调整目标：

- 从零散按钮排布升级为更统一的操作条
- 与主卡片视觉整合，减少“功能块分裂”感

### RecentTasksSidebar

现有右侧最近任务区域升级为状态面板：

- 当前处理中的任务摘要
- 最近任务列表
- 每项任务显示更清晰的状态、时间和可操作按钮

调整目标：

- 保留现有最近任务能力
- 提升任务信息密度和可读性
- 更接近样图右侧“处理中的任务”区域气质

### SettingsDialog

现有 `SettingsDialog` 保持字段内容不变，升级为更统一的设置面板：

- 表单项分组
- 输入框与目录选择器统一样式
- 保存反馈更产品化

## 主题设计

### 深色主题

默认使用深色主题，风格关键词：

- 深背景
- 柔和高光
- 轻渐变
- 高级灰卡片
- 紫蓝系强调色

主题表现：

- 页面背景采用深色基底和弱渐变
- 卡片使用略高亮的面层色
- 重要操作使用品牌强调色
- 在线、成功等状态继续使用绿色

### 浅色主题

浅色主题不是简单反色，而是独立映射同一套层级：

- 页面背景为浅灰白
- 卡片为白色或近白色
- 边框、阴影和文字对比重新调整
- 品牌强调色保留，但降低压迫感

### 主题切换行为

- 顶部提供手动切换按钮
- 默认深色启动
- 用户选择持久化到本地
- 下次启动沿用上次主题

## 页面结构草案

### 左侧装饰性侧栏

建议包含：

- 品牌 Logo
- 首页
- 最近任务
- 设置
- 关于

说明：

- 以视觉分区和未来扩展为主
- 当前阶段不做复杂路由化
- 可通过高亮、锚点或轻交互表达“所在区域”

### 顶部工具栏

建议包含：

- 品牌名或欢迎语
- 搜索外观位
- 主题切换
- 飞书状态
- 窗口控制按钮

### 主工作区

建议由三段构成：

- 欢迎区和快捷操作卡
- 链接输入主卡
- 处理流程与操作区

### 右侧任务面板

建议包含：

- 当前处理状态概览
- 最近任务列表
- 状态标签和快速操作

- 最近任务状态机

- IPC 协议

## 实施建议

建议按以下顺序实施：

1. 建立主题变量体系，支持深浅主题切换
2. 重构 `App.tsx` 的整体布局框架
3. 升级顶部工具栏和右侧面板
4. 重构主工作区卡片层级
5. 逐个升级 `UrlInput`、`StepPanel`、`ControlBar`
6. 升级设置面板样式
7. 最后统一细节：间距、阴影、状态色、响应式表现

## 验证标准

- 默认打开为深色主题
- 能手动切换浅色主题，并在重启后保留选择
- 当前所有已有功能仍可正常使用
- 停止/继续处理流程不回退
- 最近任务可正常显示与操作
- 小窗口下主要操作区仍然可用，不出现核心控件被遮挡

## 风险与控制

- 风险：布局调整过大导致现有操作路径变长
  控制：保持单页主流程不变，输入与步骤区仍为中心

- 风险：深色主题视觉过重影响可读性
  控制：使用克制的光效和阴影，不做强霓虹风

- 风险：主题切换引入样式分叉
  控制：统一使用 CSS 变量驱动，不在组件内散落写死颜色

## 结论

本次改造采用“轻后台工作台”方案：

- 默认深色、支持浅色切换
- 左侧使用装饰性侧栏
- 保留现有单页工作流
- 以卡片化、层次化、状态可视化为核心方向

这套方案能最大程度提升产品成熟度，同时避免对已稳定功能造成不必要扰动。
