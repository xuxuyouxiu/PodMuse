### 基础设施层（Sprint 1 前置依赖）

#### US-001：平台适配器架构设计

**角色**：作为开发者
**需求**：我希望有统一的 PlatformAdapter 接口定义，以便各平台按统一规范实现
**价值**：避免每个平台写一套独立逻辑，降低后续平台接入成本
**优先级**：P0
**Story Points**：3

**Acceptance Criteria**：
- [ ] Given 定义 PlatformAdapter 接口, When 包含 urlMatch/extractTitle/extractAudio/extractMetadata/getDedupKey 五个方法, Then TypeScript 编译通过且所有方法有类型定义
- [ ] Given 小宇宙现有处理逻辑, When 重构为 BilibiliAdapter 实现 PlatformAdapter, Then 小宇宙功能不受影响（回归测试通过）
- [ ] Given 新平台适配器未实现, When 调用不存在的方法, Then 有明确的类型报错而非运行时崩溃

**依赖**：无
**技术备注**：当前 podcast.ts 中的 extractAudio/fetchPodcastTitle 是内联函数，需抽取为适配器模式。小宇宙作为第一个适配器实现，验证架构可行性。

---

#### US-002：yt-dlp 检测与集成

**角色**：作为开发者
**需求**：我希望应用能检测 yt-dlp 是否可用并调用其提取音视频，以便 B 站和 YouTube 等平台能被支持
**价值**：yt-dlp 是 B 站和 YouTube 音频提取的核心依赖
**优先级**：P0
**Story Points**：3

**Acceptance Criteria**：
- [ ] Given 系统 PATH 中已安装 yt-dlp, When 应用启动时检测, Then 能正确获取 yt-dlp 路径和版本号并记录到日志
- [ ] Given 系统未安装 yt-dlp, When 应用启动时检测, Then 在设置页显示"未安装"状态和安装引导链接
- [ ] Given yt-dlp 已安装, When 传入一个 B 站视频 URL 调用提取函数, Then 输出 MP3 音频文件到指定目录且返回文件路径
- [ ] Given yt-dlp 版本低于最低要求版本, When 启动检测, Then 提示"版本过低，请更新"
- [ ] Given yt-dlp 进程异常退出, When 调用提取函数, Then 在 30 秒超时后返回错误信息而非挂起

**依赖**：无
**技术备注**：yt-dlp 路径搜索顺序：1) portable data 目录 2) 系统 PATH。stdout/stderr 需转发到应用日志面板。

---

#### US-003：通用下载器抽象

**角色**：作为开发者
**需求**：我希望有一个统一的音频下载函数，支持直接 URL fetch 和 yt-dlp 提取两种模式，以便上层处理流程不需要关心下载方式
**价值**：统一下载接口，上层代码不随新增平台而改动
**优先级**：P0
**Story Points**：2

**Acceptance Criteria**：
- [ ] Given 传入直接音频 URL, When 调用 downloadAudio(), Then 使用 fetch 流式下载并返回本地文件路径，带进度回调
- [ ] Given 传入需要 yt-dlp 的 URL, When 调用 downloadAudio(), Then 调用 yt-dlp 提取并返回本地 MP3 路径
- [ ] Given 下载过程中网络中断, When fetch 超时, Then 返回明确错误信息且清理临时文件
- [ ] Given 下载完成, When 检查输出文件, Then 文件扩展名在白名单内（mp3/m4a/wav/aac/ogg）

**依赖**：US-002
**技术备注**：现有 podcast.ts 中的 fetch 下载逻辑（lines 198-244）已较完善，可复用。新增 yt-dlp 分支即可。

### 平台识别层

#### US-004：多平台 URL 识别与路由

**角色**：作为用户
**需求**：我希望粘贴任何支持的链接时应用能自动识别平台，以便不需要手动选择来源
**价值**：零配置体验，粘贴即处理
**优先级**：P0
**Story Points**：3

**Acceptance Criteria**：
- [ ] Given 粘贴 `bilibili.com/video/BV*` 链接, When 输入框失去焦点或按回车, Then 1 秒内识别为 B 站并显示平台标识
- [ ] Given 粘贴 `youtu.be/*` 短链, When 输入框失去焦点, Then 1 秒内识别为 YouTube 并显示平台标识
- [ ] Given 粘贴 `example.com/audio.mp3`, When 输入框失去焦点, Then 识别为直接音频 URL 并显示音频图标
- [ ] Given 粘贴 `vimeo.com/xxx`（不支持平台）, When 输入框失去焦点, Then 显示"暂不支持该平台，请使用本地文件方式"
- [ ] Given 粘贴小宇宙链接, When 输入框失去焦点, Then 识别流程与现有完全一致，无任何变化
- [ ] Given URL 包含短链域名（b23.tv / youtu.be）, When 识别需要 resolve 重定向, Then 在 1 秒内完成重定向解析

**依赖**：US-001
**技术备注**：替换现有 podcast.ts:172 的 XIAOYUZHOU_PATTERN 硬门禁，改为多模式路由器。短链 resolve 可并行发起 HEAD 请求。

### B 站平台支持

#### US-005：B 站视频音频提取

**角色**：作为用户
**需求**：我希望粘贴 B 站视频链接后应用能自动提取音频，以便进入转写和笔记生成流程
**价值**：覆盖国内最大的视频知识平台
**优先级**：P0
**Story Points**：3

**Acceptance Criteria**：
- [ ] Given 粘贴 `bilibili.com/video/BV1xx411c7mD` 完整链接, When 点击处理, Then 步骤 1 显示"解析 B 站视频"，成功提取音频后进入步骤 2
- [ ] Given 粘贴 `b23.tv/xxxxxx` 短链, When 点击处理, Then 先 resolve 为完整链接再提取，最终效果同完整链接
- [ ] Given 视频包含分 P 参数 `?p=3`, When 点击处理, Then 仅提取第 3 个分 P 的音频
- [ ] Given 视频已被删除或 BV 号无效, When yt-dlp 返回 404, Then 显示"该视频不存在或已被删除"
- [ ] Given 视频需要大会员权限, When yt-dlp 返回权限错误, Then 显示"该视频需要登录或大会员权限，暂无法处理"
- [ ] Given yt-dlp 未安装, When 粘贴 B 站链接并点击处理, Then 提示"请先安装 yt-dlp"并引导到设置页

**依赖**：US-002, US-004
**技术备注**：yt-dlp 参数 `--extract-audio --audio-format mp3`。B 站标题从 yt-dlp 的 JSON metadata 中提取。

### YouTube 平台支持

#### US-007：YouTube 视频音频提取与字幕优先

**角色**：作为用户
**需求**：我希望粘贴 YouTube 链接后应用优先使用平台字幕而非 Whisper 转写，以便获得更精准的转写结果且速度更快
**价值**：YouTube CC 字幕精度远高于 Whisper，且跳过转写节省数分钟
**优先级**：P0
**Story Points**：3

**Acceptance Criteria**：
- [ ] Given YouTube 视频有英文 CC 字幕, When 点击处理, Then 步骤 3 显示"使用 YouTube 字幕"，跳过 Whisper 直接使用字幕文本
- [ ] Given YouTube 视频无 CC 字幕, When 点击处理, Then 降级为 yt-dlp 提取音频 + Whisper 转写，步骤 3 显示"使用 Whisper 转写"
- [ ] Given YouTube 视频有中文 CC 字幕, When 点击处理, Then 优先使用中文字幕（精度最高）
- [ ] Given 粘贴 `youtu.be/xxxxx` 短链, When 点击处理, Then resolve 为标准链接后正常处理
- [ ] Given 视频不可用（地区限制/已删除/私密）, When yt-dlp 返回错误, Then 显示"该视频不可用"
- [ ] Given 网络无法访问 YouTube, When 连接超时, Then 显示"无法连接 YouTube，请检查网络设置"
- [ ] Given CC 字幕格式异常（解析失败）, When 字幕处理出错, Then 静默降级到 Whisper，步骤 3 显示"字幕解析失败，切换到 Whisper"

**依赖**：US-002, US-004
**技术备注**：yt-dlp 参数 `--write-auto-sub --sub-lang zh-Hans,zh,en --skip-download` 提取字幕。字幕格式优先 vtt > srt > json3。降级逻辑在 podcast.ts 的 step 3 中处理。

### 直接 URL 支持

#### US-009：直接音视频 URL 下载处理

**角色**：作为用户
**需求**：我希望粘贴任何指向音频/视频文件的直接链接时应用能直接下载并处理，以便处理散落在各处的媒体文件
**价值**：覆盖所有未被平台适配器收录的音频/视频来源
**优先级**：P0
**Story Points**：3

**Acceptance Criteria**：
- [ ] Given 粘贴 `example.com/podcast.mp3`, When 输入框失去焦点, Then 识别为直接音频 URL，处理时使用 fetch 直接下载
- [ ] Given URL 无扩展名但 Content-Type 为 audio/mpeg, When HEAD 请求检测, Then 识别为音频 URL 并正常处理
- [ ] Given URL 返回 403（防盗链）, When 下载失败, Then 显示"该链接有访问限制，请尝试下载到本地后拖入处理"
- [ ] Given URL 指向视频文件（.mp4）, When 下载完成, Then 提取音频轨道后进入 Whisper 转写
- [ ] Given Content-Length 显示文件超过 2GB, When 下载前检测, Then 提示"文件过大（>2GB），建议下载到本地后处理"
- [ ] Given URL 包含查询参数（防盗链 token）, When 下载时, Then 保留完整 URL 用于请求

**依赖**：US-003, US-004
**技术备注**：视频文件需先通过 ffmpeg 或 yt-dlp 提取音频轨道。可复用现有 fetch 流式下载逻辑。

### Apple Podcasts 支持

**价值**：覆盖全球最大的播客分发平台
**优先级**：P1
**Story Points**：5

**Acceptance Criteria**：
- [x] Given 粘贴 Apple Podcasts 单集链接, When 点击处理, Then 成功从页面提取 RSS Feed URL，解析 RSS 找到对应单集的 enclosureUrl 并下载
- [x] Given RSS Feed 中找不到对应单集, When 匹配失败, Then 显示"RSS 中未找到该单集，播客可能已下架该期内容"
- [x] Given RSS Feed 解析超过 15 秒, When 超时触发, Then 中断解析并显示"RSS 解析超时，请检查网络或稍后重试"
- [x] Given RSS Feed URL 提取失败, When 页面解析失败, Then 显示"无法获取该播客的 RSS 源，请尝试直接粘贴音频链接"

- [x] Given enclosureUrl 指向非 MP3 格式（如 .m4a）, When 下载完成, Then 正常处理（Whisper 支持多格式）

**依赖**：US-001, US-004
**技术备注**：使用 iTunes Lookup API (itunes.apple.com/lookup?id=) 获取 RSS Feed URL，轻量级正则解析 RSS XML（无第三方依赖），og:title 匹配单集，15s 超时兜底取最新一期。

### 飞书扩展

- [ ] Given 飞书群中发送同一 B 站链接两次, When 第二次检测到, Then 去重机制生效，不重复处理

**依赖**：US-004
**技术备注**：message-parser.ts 中 PODCAST_PATTERN 扩展为多平台正则数组。去重 key 由各平台适配器的 getDedupKey() 提供。
