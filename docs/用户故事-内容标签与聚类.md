# 用户故事：内容标签与聚类

**版本：** v1.11.0 | **日期：** 2026-06-23 | **ICE Score：** 14.0

## 背景

播客笔记助手的 AI 已经在生成笔记时自动产出 `tags`（3-5个主题标签）和 `category`（4 大分类）到 frontmatter 中，但这些标签数据从未被利用。用户积累了几十期笔记后，只能按时间线或实体名称浏览，无法按主题标签快速筛选和聚类浏览。本需求旨在激活已有的标签数据，提供标签索引和聚类浏览能力。

## 现状分析

**已有的标签基础设施：**
- frontmatter 中 AI 自动生成 `tags: [标签1, 标签2, ...]`（3-5个）
- frontmatter 中 AI 自动生成 `category: 科技商业 | 每日资讯 | 社会心理 | 生活文化`
- backlinks.ts 的 `parseFrontmatter` 已能解析 `category` 字段
- `PodcastRef` 接口已有 `category` 字段
- 反向链接面板已展示 category 信息

**缺失的部分：**
- 没有扫描和索引 tags 字段
- 没有标签浏览 UI
- 没有按标签聚类/筛选的交互
- 没有标签与实体的交叉关联

## 用户故事

### US-001：标签索引与标签云（P0）

**作为** 一个积累了 30+ 期播客笔记的用户，
**我想要** 在知识关联面板看到所有标签的汇总视图，
**以便** 快速了解我的知识库覆盖了哪些主题，并点击标签筛选相关笔记。

**验收标准：**
1. 知识关联面板新增"标签"Tab，与"实体"Tab 并列
2. 展示所有播客笔记的 tags 汇总，按出现频率排序
3. 高频标签视觉更大（标签云效果），低频标签较小
4. 每个标签显示出现次数（如 "AI(12)"）
5. 点击标签 → 展开该标签下所有播客笔记列表（标题、日期、所属节目）
6. 点击笔记条目 → 在 Obsidian 中打开
7. 标签云上方显示 4 大 category 分组作为快捷筛选

**技术要点：**
- backlinks.ts 新增 `buildTagIndex(obsidianDir)` 函数，扫描所有 .md 文件的 frontmatter tags
- 标签索引数据结构：`{ tagName: string; count: number; podcastPaths: string[] }[]`
- renderer 新增 `TagCloudPanel` 组件
- 标签云用 CSS font-size 映射频率（12px-28px）

### US-002：分类聚类视图（P1）

**作为** 一个希望按主题领域浏览笔记的用户，
**我想要** 按 4 大分类（科技商业、每日资讯、社会心理、生活文化）聚类展示所有播客笔记，
**以便** 快速找到某个领域下的所有内容。

**验收标准：**
1. 知识关联面板的"标签"Tab 下方，新增"分类聚类"区域
2. 4 个分类卡片横向排列，每个卡片显示分类名 + 笔记数量
3. 点击分类卡片 → 展开该分类下所有播客笔记列表
4. 笔记列表按日期倒序排列
5. 每条笔记显示：标题、日期、节目名、标签列表
6. 同一篇笔记可能不出现在多个分类中（category 是单选）

**技术要点：**
- 复用 `buildTagIndex` 扫描过程中收集的 category 信息
- renderer 新增 `CategoryClusterView` 组件
- 4 大分类用不同颜色标识（与现有 frontmatter category 颜色一致）

### US-003：标签-实体交叉关联（P2）

**作为** 一个做主题研究的用户，
**我想要** 在某个标签下看到相关实体列表，
**以便** 发现"AI"这个标签下经常出现哪些人物、项目、概念。

**验收标准：**
1. 在标签展开的笔记列表下方，新增"相关实体"区域
2. 相关实体来自该标签下所有笔记中出现的 wiki-link 实体
3. 实体按出现次数排序，显示前 10 个
4. 点击实体 → 跳转到实体详情页（复用现有反向链接面板的实体详情）
5. 实体按类型分四组：人物、项目、概念、术语

**技术要点：**
- 从笔记正文中提取 wiki-link，与标签关联
- 交叉索引数据结构：`{ tagName → { entities: Map<entityName, count> } }`
- 可在 `buildTagIndex` 时一并收集

## 范围边界

**包含：**
- 扫描已有播客笔记的 frontmatter tags 和 category
- 标签云 UI + 分类聚类 UI
- 标签 → 笔记列表 → 实体关联的浏览链路
- 与现有反向链接面板的实体详情页打通

**不包含：**
- 标签的增删改（标签由 AI 自动生成，不支持手动编辑）
- 全文搜索功能（属于"增强搜索"需求）
- 语义相似度聚类（仅基于标签精确匹配）
- 标签合并/同义词处理（如 "AI" 和 "人工智能" 视为不同标签）
